# External dependencies

Lean is pinned by `lean-toolchain` to `leanprover/lean4:v4.24.0`. Mathlib is pinned to `f897ebcf72cd16f89ab4577d0c826cd14afaafc7` in the Lake configuration and `lake-manifest.json`; all transitive packages retain exact commit revisions in the manifest. Preserve these pins and use the repository shared tooling.

All 21 registered classical results are **explicit proposition parameters**, not new production axioms, supplied Lean proofs or hidden Maxout estimates. Their exact statements, source references, limitations and use sites are retained in `external-inputs.json`. The following table identifies every input:

| analytic-projection-completion | `BorelProjectionNullMeasurableInput` | For arbitrary standard Borel X,Y, a Borel relation R⊆X×Y has analytic first projection; for every sigma-finite Borel measure on X this projection is measurable in its completion. | crofton-regularity | `ClassicalCroftonRegularityLaw` | For the same arbitrary AC unit-sphere ψ, for almost every Gaussian D, every interior zero of D·ψ occurs at a differentiability point with D·ψ′ nonzero. There is no upper-envelope or visibility statement. |

| cauchy-perimeter | `CauchyPerimeterLaw` | For every nonempty finite deterministic planar point cloud, the geometric perimeter of its convex hull is the full-circle integral of its support function. The source's own Maxout visibility/rank estimates, local sharpness limits, selected-winner second moment and network recursions are not exemptions. The AC finite-maximum interface is a generic calculus consequence; its supporting smooth-max citation is not presented as a verbatim arbitrary-AC theorem. Crofton regularity explicitly includes the disclosed classical null-image supplements. Gaussian representation includes singular covariance as an explicit standard theorem input. No production `sorry` or new axiom was introduced.

There are no numerical certificate assets. Full contract materialization is a deferred Lean type-export step, followed by an independent semantic review; generated files are not currently present. Only the early 27-target fixed suite is already materialized.

Official Comparator uses the repository shared pinned installation. Challenge modules intentionally contain proof placeholders to specify fixed expected theorem types. They and deliberate negative-control axioms are verification fixtures, outside the production build target. The production proof closure must be checked independently of those fixtures.
