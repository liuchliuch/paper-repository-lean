# External dependencies

No paper-specific external theorem exemption or registered external sorry is used. Assumption 1.1 is the original explicit effective oracle-access promise, not a proved existence claim for arbitrary real functions. The original common finite-cube nonvanishing theorem is proved and supplied internally to OriginalTheorems.theorem_1_2 and its corollary; earlier helpers with a CommonNonvanishing parameter are retained compatibility APIs and are not the final main scope. Complexity is a mathematical ordinary binary word-pass model charging actual multiplication, long division, Euclidean rational normalization, signed floor/ceiling, finite enumeration/sorting, grid/coordinate/control loops and oracle time. It does not certify Lean VM wall-clock performance or a compiler. No external certificate assets or materialized work-directory inputs are needed.
